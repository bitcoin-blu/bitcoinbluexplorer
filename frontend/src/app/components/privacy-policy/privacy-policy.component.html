Privacy Policy

Updated: 10 November 2026

BBLU Block Explorer is a public block explorer for the Bitcoin-Blu chain. This website and its API (the "Website") are operated independently of Mempool Holdings S.A. de C.V. Mempool Holdings has no affiliation with this Website and does not sponsor or endorse it.

The Website does not offer accounts, payments, donations, or advertising. It does not use third-party analytics or third-party trackers.

What stays in your browser

If you choose a language, the Website stores that choice in a first-party cookie named lang. Display preferences, such as theme, fiat unit, and chart window, are stored in this browser's local storage. Those values stay on your device.

Server logs

The web server writes an access log of requests to this host. A log line can include your IP address, the time, the URL, and the user agent. This site does not run a separate analytics application. Log retention follows the host's ordinary log rotation. The logs are not sold or sent to an advertising network.

Transactions you broadcast

If you broadcast a transaction, the raw transaction is sent to this server and relayed to the Bitcoin-Blu network. A broadcast is public chain data once it propagates.
